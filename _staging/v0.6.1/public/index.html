Local model notes

The scanner stores five-minute local snapshots and now uses the last seven days for average price, historical volatility and trend signals. The desktop keeps the long-term history under F:\bazzarFlipper. The desktop keeps the full historical database. The laptop is collector-only: it stores only unsynced snapshots, sends them to the desktop, waits for acknowledgement, then deletes them locally. If disk space becomes critically low, the oldest unsynced snapshots are discarded first so newer data can continue to be collected.

Reverse NPC uses Hypixel item metadata, current order-book VWAP and the official daily NPC coin cap. Program updates are checked directly from a GitHub update repository; applying an update preserves the database and handoff files and rolls back if the new server fails its health check.
